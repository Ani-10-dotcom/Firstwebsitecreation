# Firstwebsitecreation

Product page for the Leoron by Srushti Gold Outer Lid Pressure Cooker (3 L), in the style of a grocery e-commerce site.

- `index.html` is the whole site: HTML, CSS and JavaScript in one file, with the product photos embedded.
- Features: image gallery, add to basket, wishlist, specifications and customer reviews.
- Price, reviews and delivery notes are sample content. Replace them with real data.

## Run locally

Open `index.html` in a browser. No build step is needed.

## Deploy

Hosted as a static site on Vercel. Every push to `main` redeploys it.
